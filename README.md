# fancyHeadTail 
## Section 1 — Command Description 
My fancyHeadTail command combines the head and tail commands into one tool. It displays the first 3 lines and the last 3 lines of a text file. 
To run my command, I open the terminal in VS Code and type: 
node fancyHeadTail.js names.txt 
The program reads the file and displays the first 3 lines and the last 3 lines. 
If I forget to enter a file name, the program displays "Missing file name". If the file does not exist, it displays "File not found".
